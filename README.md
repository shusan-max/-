# 子供服マーケット情報ボード

子供服・アパレル・ECマーケティングに関するニュースを **毎朝自動で集めて、1枚のWebページにまとめる** ツールです。

- Googleニュースから、登録したキーワードの直近7日の記事を収集
- ululu・House on the hill など、SNSで人気の子供服ブランドの動向もチェック
- カテゴリ別のタブ切り替え・キーワード絞り込みができる
- 24時間以内の記事には「NEW」マーク
- 過去30日分をためておける
- 費用は無料（GitHub の無料機能だけで動きます）

## はじめの設定（最初の1回だけ）

1. このブランチを `main` にマージする（自動収集は `main` ブランチでのみ動きます）
2. GitHub のリポジトリ画面で **Settings → Pages** を開く
   - Source：`Deploy from a branch`
   - Branch：`main` / フォルダ：`/docs` → **Save**
3. **Actions** タブ →「ニュース収集」→ **Run workflow** を押して初回収集
4. 数分後、Settings → Pages に表示されるURL（`https://<ユーザー名>.github.io/<リポジトリ名>/`）を開く

あとは毎朝6時に自動で更新されます。スマホのホーム画面にURLを追加しておくと便利です。

> 注意：GitHub Pages で公開したページは、URLを知っている人なら誰でも見られます（内容は公開ニュースのリンクのみです）。

## キーワードを変えたいとき

`config.json` を編集します（GitHub の画面上で鉛筆アイコンから直接編集できます）。

```json
{
  "name": "カテゴリ名",
  "keywords": ["検索キーワード1", "検索キーワード2"]
}
```

| 項目 | 意味 |
| --- | --- |
| `title` | ページのタイトル |
| `keep_days` | 何日前までの記事を残すか |
| `max_per_keyword` | 1キーワードあたり最大何件取るか |
| `categories` | カテゴリとキーワードの一覧 |

### 注目ブランドを追加したいとき

「注目SNSブランド」カテゴリの `keywords` に、ブランド名を `"\"ブランド名\" 子供服"` の形で追加します。
ブランド名を `\"` で囲むと、その名前がそのまま含まれる記事だけに絞り込めます（似た言葉の記事が混ざりにくくなります）。

```json
"keywords": [
  "\"ululu\" 子供服",
  "\"House on the hill\" 子供服",
  "\"新しいブランド名\" 子供服"
]
```

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `config.json` | 収集キーワードの設定 |
| `collector/collect.py` | ニュースを集めてページを作るプログラム |
| `collector/template.html` | ページのデザイン |
| `docs/index.html` | 完成したページ（自動生成） |
| `docs/data.json` | 集めた記事データ（自動生成） |
| `.github/workflows/collect.yml` | 毎朝の自動実行の設定 |

## 手元のパソコンで動かす場合

Python 3.9 以上があれば追加インストール不要です。

```
python collector/collect.py
```

実行後、`docs/index.html` をブラウザで開くと見られます。
