# 子供服マーケット情報ボード

子供服の情報を **毎朝自動で集めて、Webページにまとめる** ツールです。ページは3つあります。

| ページ | 内容 |
| --- | --- |
| ニュース（`index.html`） | 子供服に関係するニュースだけを、カテゴリ別・キーワード検索で見られる |
| 市場環境（`market.html`） | 出生数や子供服の市場規模などの統計グラフ、市場のポイント、ニュースによく出る言葉、市場ニュース |
| SNSブランド分析（`brands.html`） | ululu・House on the Hill など SNS で人気のブランドの特徴・比較表・自分のお店に活かせるポイント、ブランドの最新ニュース |

- Googleニュースから直近7日の記事を収集し、過去30日分をためておく
- 記事タイトルに「子供服」「キッズ」「ベビー」などが入っている記事だけを残し、事件・政治などの記事は除外
- 同じニュースを別の媒体が報じた“ほぼ同じ記事”は1件にまとめる
- 費用は無料（GitHub の無料機能だけで動きます）

## はじめの設定（最初の1回だけ）

1. このブランチを `main` にマージする（自動収集は `main` ブランチでのみ動きます）
2. GitHub のリポジトリ画面で **Settings → Pages** を開く
   - Source：`Deploy from a branch`
   - Branch：`main` / フォルダ：`/docs` → **Save**
3. **Actions** タブ →「ニュース収集」→ **Run workflow** を押して初回収集
4. 数分後、Settings → Pages に表示されるURL（`https://<ユーザー名>.github.io/<リポジトリ名>/`）を開く

あとは毎朝6時に自動で更新されます。スマホのホーム画面にURLを追加しておくと便利です。

> 注意：GitHub Pages で公開したページは、URLを知っている人なら誰でも見られます（内容は公開ニュースのリンクのみです）。

## 設定を変えたいとき

どのファイルも GitHub の画面上で鉛筆アイコンから直接編集できます。保存すると、次の自動収集から反映されます。

### 集めるキーワード・除外する言葉（`config.json`）

| 項目 | 意味 |
| --- | --- |
| `categories` | ニュースのカテゴリと検索キーワード |
| `relevance.include_any` | 記事タイトルにこのどれかが入っている記事だけ残す |
| `relevance.exclude_any` | 記事タイトルにこれが入っている記事は除外する |
| `trend_terms` | 市場環境ページで「ニュースに多く出てくる言葉」として数える言葉 |
| `keep_days` / `max_per_keyword` | 何日分残すか / 1キーワードあたり最大何件取るか |

関係ない記事が混ざったら `exclude_any` に言葉を足し、必要な記事が消えていたら `include_any` に言葉を足してください。

### 分析するブランド（`brands.json`）

ブランドを1つ追加するには、`brands` の中に同じ形でブロックを足します。`aliases` に書いた名前（英語・カタカナ両方がおすすめ）でニュースも自動で集めます。
「ウルル」のように一般的な言葉と紛らわしい名前は `"match_with_kids_term": true` を付けると、子供服関係の言葉も入った記事だけを拾います。
分析の文章（特徴・強み・活かせるポイント）は手入力です。

### 市場の統計（`market.json`）

出生数・市場規模などの数字は手入力です。新しい統計が発表されたら、数値と出典を追記してください。

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `config.json` | 収集キーワードの設定 |
| `brands.json` | SNSブランド分析の内容 |
| `market.json` | 市場環境の統計データ |
| `collector/collect.py` | ニュースを集めてページを作るプログラム |
| `collector/templates/` | ページのデザイン |
| `docs/*.html` | 完成したページ（自動生成） |
| `docs/data.json` | 集めた記事データ（自動生成） |
| `.github/workflows/collect.yml` | 毎朝の自動実行の設定 |

## 手元のパソコンで動かす場合

Python 3.9 以上があれば追加インストール不要です。

```
python collector/collect.py
```

実行後、`docs/index.html` をブラウザで開くと見られます。
設定ファイルだけ変えてページを作り直したいときは `python collector/collect.py --offline`（ニュースは取りに行きません）。
